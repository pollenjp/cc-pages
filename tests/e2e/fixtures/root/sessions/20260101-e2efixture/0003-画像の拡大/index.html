画像の拡大

このページは e2e の固定 fixture。中身を変えると PR に貼られるスクショも変わる。 図をクリックすると overlay で拡大でき、overlay から画像だけを別タブで開ける。

1. assets の画像

assets/ に置いた画像を <img> で貼ったもの。別タブでは /p/…/assets/shot.svg がそのまま開く。

2. inline SVG の図

フラグメントに直接書いた <svg>。単体のファイルが無いので、別タブは その場で組み立てた blob: を開く。色は currentColor なので ライトでもダークでも本文と同じ見え方になる。

3. 既にリンクになっている画像

書き手が自分で <a> に包んだ画像は overlay の対象外。クリックすると リンク先へ飛ぶ。
